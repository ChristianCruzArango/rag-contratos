indexado ahora mismo**.

Las cifras salen de `/api/rag/stats`. Si el índice está vacío lo dice, y si el
backend no responde lo dice también — no hay estado de maqueta.

vector que dibujaba era una onda inventada, no un embedding medido, y eso
contradice lo único que esta página promete. La demostración de verdad está en
