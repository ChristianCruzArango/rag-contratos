# `viz/chunk-river/` — El texto partido

El corte no es cada N caracteres a ciegas: primero por cláusula o anexo, y sólo
dentro de una cláusula demasiado larga se sigue por párrafo. Así un fragmento
nunca mezcla dos cláusulas y puede citar su número y su página.

Entre pieza y pieza se dibuja la **costura**: los caracteres del final del
fragmento anterior que se repiten al principio del siguiente.
