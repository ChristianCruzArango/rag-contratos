# `viz/cosine-dial/` — La distancia coseno

Dos textos se comparan por el **ángulo** entre sus vectores, no por lo lejos que
estén del origen. Ángulo pequeño = hablan de lo mismo, aunque uno sea largo y el
otro corto.

Por eso «¿cuánto sube el arriendo?» encuentra una cláusula que dice «reajuste
anual del canon» sin compartir una sola palabra.
